# Taste-Skill UI/Frontend Directives (Leonxlnx/taste-skill)

This project integrates **Taste-Skill** rules and tuning parameters to guarantee high-taste, high-craft, anti-slop frontend implementations.

---

## Core Pillars & Directives

### 1. Anti-Boilerplate & High Design Variance
- Reject generic boilerplate templates, identical 3-column stacked icon cards, and predictable AI UI patterns.
- Apply distinct layout compositions, authentic materials, and intentional whitespace tailored specifically to spatial planning, disaster analysis, and technical reports.

### 2. Typographic Intent & Visual Density
- Pair purposeful display typography with crisp monospace and sans-serif data layers.
- Maintain optical rhythm and density: data grids, chips, and progress bars align with mathematical precision.

### 3. Production-Ready, Complete Outputs (Output-Skill)
- Never output partial mock placeholders or unhandled click events.
- All interactions (editing, filtering, status toggling, syncing) must execute with robust state management.

### 4. Cinematic Tone & Cohesion
- High-contrast visual structure: distinctive dark headers, warm neutral data surfaces, crisp theme color-coding (Ulaşım, Teknik Altyapı, Lojistik).
- Purposeful accent coloring reserved for status changes and critical data highlights.
